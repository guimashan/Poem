# 玄天上帝感應靈籤

龜馬山紫皇天乙真慶宮「玄天上帝感應靈籤」靜態網站，共 **49 首**籤詩。

- 網址：https://poem.guimashan.org.tw
- 託管：GitHub Pages（本 repo，`main` 分支根目錄）
- 來源：原 Google Sites 版本 `sites.google.com/view/guimashen-poem`

## 用字原則（重要）

**本站籤詩文字與廟方原文完全一致，一字未改。**

原站使用古字／異體字（例如 踨、劎、閑、寍、裹、隄、恠、窓、筭、箇、悮、坵 等），
這些是廟方一貫的用字風格，**不是錯字，請勿自行改為現代通行字**。

已逐字比對確認：49 首籤詩與 Google Sites 原文零差異。

## 結構

```
index.html          首頁（橫幅 + 49 籤選單）
poem/NN.html        各籤頁（01–49）
style.css           全站樣式
assets/banner.css   橫幅圖（base64 內嵌，無二進位檔）
CNAME               poem.guimashan.org.tw
```

## 各籤內容

每籤含 9 個欄位：聖意、謀望、家宅、婚姻、失物、官事、行人、占病、解曰。

## 修改方式

籤詩文字直接編輯 `poem/NN.html`。修改前請先確認廟方正式版本用字。
